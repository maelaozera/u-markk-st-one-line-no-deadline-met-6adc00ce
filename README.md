## Entry

A single-line joke giving an excuse for a missed deadline (under 200 characters, one sentence, punch at the end). The narrator was ready to meet the deadline — but their motivation itself called in sick and left no forwarding address, so the blame lands on a personified motivation rather than a plain apology.

## How to run

Requires Node 22 or later (no dependencies):

```sh
node main.ts
```

This writes the one-line entry to `/output/entry.txt`, after self-checking the gate: 1–200 characters, a single line, not only whitespace.
